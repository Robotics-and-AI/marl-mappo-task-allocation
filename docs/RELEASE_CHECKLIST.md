# Public release checklist

Before publishing on GitHub as `marl-mappo-task-allocation`:

- [ ] Create/rename the repository as `marl-mappo-task-allocation`.
- [ ] Add `README.md`.
- [ ] Add `requirements.txt`.
- [ ] Add `pyproject.toml` with `name = "marl-mappo-task-allocation"`.
- [ ] Add `.gitignore`.
- [ ] Choose a license and add `LICENSE`.
- [ ] Keep `task_templates/task_templates.yaml` tracked.
- [ ] Regenerate datasets with `python make_dataset.py` rather than committing generated `.npz` files by default.
- [ ] Keep `results/`, `results_mappo_bidding/`, and Ray outputs ignored.
- [ ] Decide whether the trained checkpoint should be shared through GitHub Releases, Git LFS, or regenerated by users.
- [ ] Run a syntax check before committing:

```bash
python -m py_compile \
  task_generator.py \
  heterogeneous_team_env.py \
  make_dataset.py \
  extract_eval_only_npz.py \
  train.py \
  task_allocation_interface.py \
  scripts/dataset_npz_to_txt.py \
  scripts/eligibility_report_basic.py \
  scripts/eligibility_report_env_sampling.py \
  scripts/evaluate_checkpoint_on_evalset.py
```

Important final fixes included in this reviewed bundle:

1. `scripts/eligibility_report_basic.py`, `scripts/eligibility_report_env_sampling.py`, and `scripts/evaluate_checkpoint_on_evalset.py` now add the repository root to `sys.path`, so they can be run as `python scripts/<script>.py` from the repository root.
2. Script usage examples were updated to include the `scripts/` prefix.
3. `train.py` now points users to `task_allocation_interface.py` instead of the previous GUI filename.
4. `task_generator.py` already points to `task_templates/task_templates.yaml`.
