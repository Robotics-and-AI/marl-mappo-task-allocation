# Package name

The public repository/distribution name is:

```text
marl-mappo-task-allocation
```

The Python source files keep their current import names, for example:

```python
from task_generator import NLTaskGenerator
from heterogeneous_team_env import HeterogeneousTeamEnv
```

This is intentional: hyphens are valid in GitHub repository names and Python distribution names, but not in Python import identifiers.
